## 1. 实时监测指标体系

### 1.1 一级关键指标（KPI）

直接影响成衣质量和客户满意度的指标，必须实时监控：

| 指标 | 监测目的 | 正常范围参考 | 数据来源 | 采样频率 |
|-----|---------|------------|---------|---------|
| 验货批次合格率（qc_pass_rate） | 衡量工厂成衣整体质量水平 | ≥95%（自营）/ ≥90%（联营） | 厂检验货报告表 | 批次级 |
| 仓检不合格率（qi_defect_rate） | 衡量到货成衣到仓质量 | ≤3% | 仓检验货报告表 | 批次级 |
| 包材错误率（pkg_error_rate） | 衡量包材标签准确率 | ≤2% | 包材检验报告表 | 批次级 |
| 标签错误率（label_error_rate） | 衡量标签准确性 | ≤1% | 包材检验报告表 | 批次级 |
| 退货率（return_rate） | 衡量售后质量 | 按品类设定目标值 | 多维表格汇总 | 月级 |
| 负评率（negative_review_rate） | 衡量消费者体验 | 按品类设定目标值 | 多维表格汇总 | 月级 |

### 1.2 二级辅助指标

用于根因推断和趋势预警：

| 指标 | 监测目的 | 数据来源 |
|-----|---------|---------|
| 缝制缺陷批次率 | 区分缺陷类型（缝制/面料/标签） | 厂检验货报告表 |
| 面料瑕疵批次率 | 判断是否为面料批次性问题 | 厂检验货报告表 |
| 标签包材错误批次率 | 判断是否为包装环节问题 | 包材检验报告表 |
| 连续不合格工厂数 | 识别系统性质量下滑工厂 | 多工厂对比 |
| 新供应商缺陷率 | 监控新供应商质量磨合期 | 供应商质量台账 |

### 1.3 衍生指标（计算得出）

| 衍生指标 | 计算公式 | 用途 |
|---------|---------|------|
| 验货批次合格率 | 合格批次/总抽检批次×100% | 整体质量评估 |
| 仓检批次不合格率 | 不合格批次/总到货批次×100% | 到货质量评估 |
| 工厂质量指数 | 加权平均（验货×0.4 + 仓检×0.3 + 客诉×0.3） | 供应商排名 |
| 品类质量波动率 | 近30天合格率标准差 | 质量稳定性评估 |

## 2. 指标基线与动态阈值

### 2.1 静态阈值（企业内控目标）

| 指标 | 目标值 | 预警阈值 | 告警阈值 |
|-----|-------|---------|---------|
| 自营验货批次合格率 | ≥95% | <90% | <85% |
| 联营验货批次合格率 | ≥90% | <85% | <80% |
| 仓检批次不合格率 | ≤3% | >5% | >8% |
| 包材错误率 | ≤2% | >3% | >5% |
| 标签错误率 | ≤1% | >2% | >3% |
| 单批次不合格率 | ≤5%（单批次抽检中不合格品占比） | >8% | >15% |

### 2.2 动态基线（统计方法）

当企业目标值调整或品类差异较大时，使用滑动窗口统计建立动态基线：

- **基线计算**：取近30天或近50个批次数据，计算均值μ和标准差σ
- **预警阈值**：μ - 2σ（针对合格率）或 μ + 2σ（针对不合格率）
- **告警阈值**：μ - 3σ（针对合格率）或 μ + 3σ（针对不合格率）
- **基线刷新**：每完成10个批次或每月刷新一次；异常期间暂停刷新

### 2.3 品类差异化阈值

| 品类 | 合格率目标 | 说明 |
|------|---------|------|
| 贴身衣物（文胸/内裤） | ≥95% | 贴身穿着，安全要求高 |
| 家居服/保暖 | ≥92% | 舒适度要求高 |
| 外穿服装 | ≥90% | 外观要求高 |
| 童装（GB 31701） | ≥95% | 安全强制要求，A类标准 |
| 家纺（床品/毛巾） | ≥90% | 耐用性要求高 |

## 3. 异常检测规则

### 3.1 阈值型异常

| 指标 | 越限方向 | 严重级别 | 规则说明 |
|-----|---------|---------|---------|
| 批次合格率 | 越下限 | 严重 | 单批次合格率低于目标值20%以上 |
| 仓检不合格率 | 越上限 | 严重 | 单批次仓检不合格率>8% |
| 标签错误率 | 越上限 | 告警 | 标签错误率>3% |
| 连续不合格批次 | 上升趋势 | 告警 | 同工厂/同款连续2个批次不合格 |

### 3.2 统计型异常

| 指标 | 检测方法 | 触发条件 | 级别 |
|-----|---------|---------|------|
| 批次合格率 | 3σ规则 | 单批次合格率低于μ-3σ | 告警 |
| 月度合格率 | 环比规则 | 环比下降超5个百分点 | 预警 |
| 品类合格率 | 对比规则 | 某品类合格率低于其他品类均值5个百分点 | 预警 |
| 新供应商 | 首验规则 | 新供应商首批验货不合格 | 预警 |

### 3.3 关联型异常

单一指标正常但参数间关系异常：

| 关联规则 | 异常条件 | 推断根因方向 |
|---------|---------|------------|
| 验货合格 + 仓检不合格 | 厂检通过但到仓发现质量问题 | 仓储/运输环节或工厂弄虚作假 |
| 面料换批 + 仓检不合格上升 | 面料批次变化后不合格率上升 | 面料性能波动/批次管理问题 |
| 验货合格 + 客诉退货率上升 | 厂检通过但售后问题增加 | 检测条件不足（未覆盖实际穿着场景）|
| 包材换厂 + 标签错误率上升 | 更换包材供应商后标签错误增加 | 新供应商培训/沟通不足 |

### 3.4 工厂状态型异常

- 工厂连续3个批次不合格 → 立即严重告警，触发供应商质量改善流程
- 新供应商首批验货不合格 → 预警，新供应商需重新审核资质
- 产前会覆盖率低于100% → 告警，未开产前会的批次质量风险高

## 4. 告警分级与响应

### 4.1 告警级别定义

| 级别 | 名称 | 判定标准 | 响应要求 |
|-----|------|---------|---------|
| L1 | 预警（Warning） | 指标低于目标5个百分点内；连续2个批次不合格 | 自动记录，输出提示，纳入趋势观察 |
| L2 | 告警（Alert） | 指标低于目标10个百分点；连续3个批次不合格；单批次严重缺陷 | 自动溯源，输出可疑根因，建议人工确认，推送飞书通知 |
| L3 | 严重（Critical） | 指标低于目标20个百分点；连续5个批次不合格；涉及安全/法规问题（pH/甲醛/偶氮） | 立即自动溯源，输出紧急处置建议，立即推送飞书任务，暂停出货 |

### 4.2 告警抑制与去噪

- **抖动抑制**：同一指标在48小时内重复触发相同级别告警，合并为一条并记录频次
- **批次去噪**：若同批次在验货和仓检环节结果不一致，优先采信仓检结论（到货实物为准）
- **季节性调整**：换季新品首批合格率低于目标时，降低告警级别（磨合期）

## 5. 自动溯源流程

当异常触发后，自动执行以下溯源链路：

### 5.1 时间定位

1. 记录异常触发时间戳 T0（验货日期/仓检日期）
2. 确定异常时间窗口（通常为 T0 前后各15天）
3. 识别该窗口内的批次标识（款号 + 工厂 + 批次号）

### 5.2 批次关联

1. 获取当前批次及前后各N个批次（共前后各5批次）的质量数据
2. 对比相邻批次的合格率变化，识别突变点
3. 若异常跨越换料/换线时刻，分别分析前后批次的特征

### 5.3 工序回溯（优先级顺序）

**第一优先级：面料批次溯源**
- 检查该批次对应的面料批次号
- 对照面料质检报告（克重/缩水率/pH值/色牢度）
- 若面料指标异常且与成衣缺陷类型对应，标记为主要根因

**第二优先级：工艺执行溯源**
- 检查该工厂是否开了产前会
- 检查工艺单版本是否与封样一致
- 检查验货报告中的首件确认记录

**第三优先级：包装环节溯源**
- 检查包材批次是否与验货时一致
- 检查标签换版记录
- 检查仓检与厂检的结论对比

**第四优先级：仓储运输溯源**
- 若厂检合格但仓检不合格，检查仓储条件记录
- 检查到货搬运记录（是否有挤压/污染风险）

### 5.4 根因推断与缺陷预判

| 回溯发现 | 可能缺陷类型 | 风险等级 | 建议措施 |
|---------|------------|---------|---------|
| 面料pH值/甲醛超标 + 贴身衣物 | 安全危害（pH/甲醛/偶氮） | 严重 | 立即暂停出货，送检第三方，整改面料厂 |
| 氨纶面料批次 + 缝制爆口集中 | B缝制问题（爆口） | 高 | 整改工厂工艺，使用弹性线迹 |
| 标签换版后 + 标签错误集中 | D标签包材错误 | 高 | 销毁旧版标签，整改标签管控流程 |
| 产前会未开 + 批量缝制缺陷 | 工艺执行问题 | 高 | 要求工厂补开产前会，加强工艺督导 |
| 验货合格 + 仓检不合格 + 存储无异常 | 质量弄虚作假嫌疑 | 严重 | 突击复查，下发整改任务，暂停新单 |

### 5.5 溯源输出格式

```
【异常告警】
- 时间：2026年6月15日
- 款号：YKS-2026-0666
- 工厂：XX制衣厂
- 异常指标：仓检批次不合格率 = 12.3%（目标值≤3%）
- 告警级别：L2-告警

【自动溯源结论】
- 可疑根因方向：面料批次性能波动 + 工厂工艺执行不到位
- 关键证据：
  1. 该批次面料为换缸批次（6月第3周），氨纶含量实测值12%（设计值10%），面料弹性超出工艺参数范围
  2. 该批次产前会记录显示"未开产前会"（工厂自行生产）
  3. 同款前3个批次仓检不合格率分别为2.1%、1.8%、2.3%，本批次突升至12.3%
- 关联风险：批量爆口（高弹性面料未使用弹性线迹）
- 建议处置：
  1. 立即暂停该批次出货，全检后重新判定
  2. 通知工厂：面料换批必须重开产前会，调整线迹工艺
  3. 采购经理介入：跟进面料批次变更通知机制
  4. 截止日期：2026年6月20日前完成整改
```

## 6. 实时看板输出规范

### 6.1 正常状态输出

- 当前批次质量概览（自营/联营/仓检各合格率）
- 近30天合格率趋势（折线图）
- TOP3问题款号/工厂（按不合格批次数量排序）
- 各品类质量对比（雷达图或柱状图）

### 6.2 异常状态输出

- 异常告警卡片（级别、款号、工厂、指标、当前值、目标值、持续时间）
- 溯源结论摘要（关联批次、可疑工序、根因推断）
- 建议处置措施（按紧急程度排序）
- 待下发飞书任务清单

### 6.3 与离线诊断的衔接

- 实时监测中发现的异常可一键生成离线分析报告
- 自动将异常批次、关联数据预填入报告模板
- 引导用户补充缺陷照片，完成完整诊断
- 自动生成飞书任务并指定责任人
