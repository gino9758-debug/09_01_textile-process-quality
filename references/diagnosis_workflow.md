# 针织服装质量异常诊断流程

## 诊断方法论

### 五步诊断法

1. **现象确认**
   - 确认缺陷类型（缝制/标签包材/仓检不合格）、位置、严重程度、发生频率（偶发/批量）
   - 收集缺陷照片、验货报告、仓检记录等证据
   - 确认缺陷发生的时间范围、涉及款号、工厂名称

2. **数据收集**
   - 调取验货记录（款号/工厂/批次/QC结论/不合格项）
   - 调取仓检记录（到货日期/QI结论/不合格描述）
   - 调取面料质检数据（克重/缩水率/色牢度/pH值/甲醛）
   - 调取包材检验记录（标签内容/款号/尺寸）
   - 调取工厂历史质量数据（历史缺陷率/同类问题发生情况）
   - 调取产前会记录（工艺单/封样批准/首件确认）

3. **根因分析**
   - 对照缺陷成因库（`references/defects_catalog.md`），逐项排查可能因素
   - 结合飞书多维表格历史数据（验货记录/仓检记录）进行趋势分析
   - 采用鱼骨图/5Why法追溯根本原因
   - 区分主要因素和次要因素，锁定责任工序

4. **验证确认**
   - 对假设根因进行数据验证（对照验货报告/面料质检数据）
   - 检查同期其他批次是否出现类似缺陷（确认是工厂系统性问题还是偶发事件）
   - 确认根因与缺陷发生的时序关系（哪个工序先出问题）

5. **对策制定**
   - 针对根因制定整改方案（具体到工序/参数/要求）
   - 制定预防性检查清单（产前会检查项/面料入库检查项/包材验收检查项）
   - 设定跟踪指标和验证标准
   - 自动下发飞书任务给采购经理/工厂对接人

## 数据需求清单

### 必取数据（优先）

| 数据类别 | 具体参数 | 数据来源 |
|---------|---------|---------|
| 验货记录 | 款号/工厂/批次/QC结论/缺陷描述 | 多维表格「认证QC/QC-自营-厂检-验货报告」|
| 仓检记录 | 款号/到货日期/仓检结论/不合格项 | 多维表格「QI-仓检-验货报告」 |
| 包材检验 | 包材批次/标签内容/款号匹配/印刷质量 | 多维表格「包材-QC-厂检-查货报告」 |
| 面料质检 | 面料批次/克重/缩水率/色牢度/pH值/甲醛 | 面料检验流程及要求文档 |
| 供应商信息 | 工厂名称/历史质量记录/免检资质 | 多维表格「管理-供应商信息」 |

### 辅助数据（按需）

| 数据类别 | 具体参数 | 数据来源 |
|---------|---------|---------|
| 产前会记录 | 工艺单版本/封样批准/首件确认 | 产前会资料规范标准文档 |
| 质量罚款记录 | 罚款批次/金额/整改要求 | 供应商客诉处罚标准文档 |
| 质量改善台账 | 改善措施/完成情况/跟踪记录 | 多维表格「管理-供应商质量改善台账」 |

## 常见场景快速诊断路径

### 场景B1：批量出现缝制断线

**第一步**：确认断线位置（接缝处/领口/袖窿/裤脚）
**第二步**：检查同期验货记录 → 断线是哪个工厂/批次发生的？
**第三步**：检查断线工厂的历史质量记录 → 是否为该厂首次出现？
**第四步**：检查面料成分 → 是否为高弹性面料（氨纶含量>8%）？
**第五步**：检查验货报告中的机器设备记录 → 断线是否与特定设备相关？
**第六步**：检查操作工记录 → 是否为换班后断线集中？

**高概率根因排序**：
1. 缝纫线张力未调好 + 操作工技能不足
2. 高弹性面料未使用弹性线迹
3. 面料换批（氨纶含量波动）未通知调整工艺
4. 设备保养不到位（送布牙磨损）

---

### 场景B2：批量出现包材/标签错误

**第一步**：确认错误类型（洗标内容错误/款号贴错/尺码偏差）
**第二步**：检查标签印刷批次号 → 是否为旧版标签？
**第三步**：检查仓检记录 → 错误是在厂检时已存在还是仓检环节新发？
**第四步**：检查工厂包材验收记录 → 工厂是否对包材进行过核对？
**第五步**：检查标签版本管控记录 → 是否有变更通知？

**高概率根因排序**：
1. 换款时旧标未销毁/新标未及时到位，用旧标代替
2. 标签到货时工厂未核对，直接使用
3. 供应商（标厂）印刷错误，工厂未检验直接使用
4. 多款混线生产时包材管理混乱

---

### 场景E：仓检不合格全链路溯源

**第一步**：确认仓检不合格的具体项目（外观/尺寸/标签/缝制/配件）
**第二步**：反查验货记录 → 该批次厂检是否合格？合格的话问题出在哪里？
**第三步**：若厂检合格 → 问题可能在仓储/运输环节（存储污染/挤压变形）
**第四步**：若厂检不合格 → 检查工厂工艺执行记录（产前会/首件确认）
**第五步**：检查面料批次 → 是否与验货时的面料批次一致？
**第六步**：综合以上信息，定位根因并给出整改任务

**高概率根因排序**：
1. 厂检合格但仓检不合格 → 仓储/运输环节产生的新问题（存储条件/搬运损坏）
2. 厂检不合格且仓检不合格 → 工厂工艺执行不到位（未做产前会/未按封样执行）
3. 面料换批导致的面料性能波动 → 面料质检流程缺失

## 报告输出规范

### 质量分析报告结构

1. **缺陷概述**
   - 缺陷类型、发现时间、涉及款号/工厂、发生频次
   - 缺陷照片/验货报告截图（如有）

2. **过程数据回溯**
   - 验货记录数据表（款号/工厂/批次/合格率）
   - 仓检记录数据表（如涉及）
   - 面料质检数据（如涉及）

3. **根因分析**
   - 排查过程（逐项排查清单）
   - 主要根因及证据
   - 次要影响因素
   - 责任工序定位

4. **整改方案**
   - 具体整改动作（到工序级别）
   - 责任人（采购经理/工厂对接人）
   - 截止日期

5. **预防措施**
   - 关键控制点（KCP）清单
   - 监控指标和预警阈值
   - 验证跟踪计划

6. **附件**
   - 原始数据记录
   - 相关检验报告

### 自动下发任务规范

所有质量异常分析报告完成后，必须自动触发飞书任务创建：

```
任务类型：质量异常整改
验收标准：XX日内无同类缺陷批次出现
逾期未闭环：自动升级至采购总监
```
