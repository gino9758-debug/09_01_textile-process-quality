# 纺织服装工艺质量分析

纺织服装（针织贴身衣物优先）工艺质量分析与异常诊断 Skill（Textile & Garment Process Quality Analysis）

## 项目解决什么问题

品质异常归因长期依赖个人经验，缺陷分类、诊断路径、跨部门口径不统一；质量月会报告数据分散、溯源困难。本技能把缺陷分类体系、离线根因诊断、在线实时监测标准化，让质量异常处理从"凭经验"变成"按路径"。

## 主要功能

| 能力 | 说明 |
|------|------|
| 缺陷分类体系 | A 面料问题（起球/缩水/色差/破洞）、B 缝制缺陷（断线/爆缝/错位/偏位）、C 安全与化学危害（pH/甲醛/偶氮/阻燃）、D 标签包装错误、E 仓检不合格溯源 |
| 离线根因诊断 | 五步诊断法 + 缺陷目录（defects_catalog）+ 常见场景快速诊断路径，输出品质异常报告与纠正措施方案 |
| 在线实时监测 | 飞书多维表格数据接入、监测指标体系、异常检测与自动溯源（references/realtime_monitoring、mes_api_integration） |
| 覆盖品类 | 针织贴身衣物（文胸/保暖/家居服/袜子）、外套、童装（GB 31701）、家纺 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- Agent 支持 Skill 加载
- 在线监测模式需要飞书多维表格数据接入能力

## 使用方法

触发场景：质量异常报告、纠正措施方案、实时质量监测、质量月会汇报。Agent 会根据问题类型自动路由到离线诊断或在线监测模式。

## 输入输出示例

**输入：** 分析这批文胸的缩水率超标异常，给出根因和纠正措施
**输出：** 按缺陷目录分类定位（面料问题）+ 五步诊断法根因分析 + 纠正措施建议

**输入：** 从飞书多维表格接入本周质检数据，生成质量月会报告
**输出：** 监测指标汇总 + 异常批次预警 + 溯源结论
